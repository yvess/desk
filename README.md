# desk #

Tool for administration and billing of services, also a DNS editor.

See also [desk-inspector](https://github.com/yvess/desk-inspector)

## Upgrading ##

Running the old python2 version? See
[docs/upgrade-master-to-python3.md](docs/upgrade-master-to-python3.md) — the
Python 3 version moves to CouchDB 3.5 and drives PowerDNS through its HTTP API,
so it needs a data migration rather than a redeploy.
